================================================
  COMO ATUALIZAR AS BASES (GitHub - automático)
================================================

Você NÃO precisa rodar Python no PC.

O site agora tem uma página inicial (índice.html) com dois painéis:
  /food/    -> Food Service (aba COMPARAT_FOOD)
  /varejo/  -> Estoque Varejo (aba Estoque, categoria VAREJO)

Os dois são gerados a partir do MESMO Geral.xlsx, que fica na raiz
do site (mesma pasta do prepare_data.py).

1. Coloque o Geral.xlsx novo na RAIZ do repositório
   (mesma pasta do prepare_data.py — não dentro de /food/ ou /varejo/).

2. Envie para o GitHub:
     git add Geral.xlsx
     git commit -m "Atualiza base Excel"
     git push

3. O GitHub Actions roda sozinho, gera food/data.js e varejo/data.js
   e faz commit dos dois.

4. Espere 1–3 minutos e abra o site com Ctrl+F5.

------------------------------------------------
PRIMEIRA VEZ (ativar Actions)
------------------------------------------------
- No GitHub: aba Actions → se pedir, habilite workflows.
- Settings → Actions → General → permita workflows
  (permissão de leitura e escrita / Read and write).

------------------------------------------------
RODAR NA MÃO (se precisar)
------------------------------------------------
Actions → "Atualizar data.js a partir do Excel" → Run workflow

------------------------------------------------
ARQUIVOS IMPORTANTES
------------------------------------------------
  Geral.xlsx              ← você só atualiza este (fica na raiz)
  prepare_data.py         ← conversor único (gera os dois data.js)
  index.html, style.css   ← página inicial (hub)
  food/                   ← painel Food Service (data.js gerado)
  varejo/                 ← painel Estoque Varejo (data.js gerado)
  .github/workflows/...   ← automação
